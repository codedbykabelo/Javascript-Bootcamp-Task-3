## Project Overview

This project was developed as part of the JavaScript Bootcamp Task 3 assignment.

The application is a client-side Signup Portal that demonstrates:

* HTML form creation
* Client-side validation
* Timing events
* Synchronous programming
* Asynchronous programming

## Project Structure

### index.html

Contains the user interface and signup form.

### validation.js

Handles:

* Username validation
* Email validation
* Password validation
* Terms checkbox validation
* Error message display

### async.js

Handles:

* Countdown timer using setInterval()
* Delayed student retrieval using setTimeout()
* Synchronous execution demonstration
* Student database management

## Features

* Signup form

* Resend verification countdown
* Student database
* Synchronous JavaScript demonstration
* Asynchronous JavaScript demonstration
