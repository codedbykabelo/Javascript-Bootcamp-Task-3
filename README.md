This branch implements client-side form validation using JavaScript.

## Features Implemented

* Form submission handling
* Prevention of default form submission
* Username validation
* Email validation using Regular Expressions (Regex)
* Password length validation (minimum 8 characters)
* Terms and Conditions validation
* Error message display
* Invalid input highlighting using red borders

## Files

* index.html
* validation.js

## Validation Rules

1. Username cannot be empty.
2. Email must match a valid email format.
3. Password must contain at least 8 characters.
4. Terms and Conditions must be accepted before submission.

## Purpose

The purpose of this branch is to ensure that user input is validated before form data is processed.
