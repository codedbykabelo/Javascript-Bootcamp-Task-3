This branch contains the user interface structure for the Signup Portal application.

 Features Implemented

* Basic HTML document structure
* Signup form creation
* Username input field
* Email input field
* Password input field
* Terms and Conditions checkbox
* Submit button
* Resend Verification button
* JavaScript file connections



 Purpose

The purpose of this branch is to create the foundation of the application's user interface before adding validation and asynchronous functionality.
