This branch focuses on asynchronous programming concepts in JavaScript.

## Features Implemented

* Resend Verification countdown timer
* setInterval implementation
* clearInterval implementation
* Student database creation
* Synchronous execution demonstration
* setTimeout implementation for delayed data retrieval

## Files

* index.html
* async.js

## Student Database

The application contains a sample student database with the following fields:

* ID
* First Name
* Last Name
* Email
* Course
* Age

## Concepts Demonstrated

### Synchronous Programming

Shows how JavaScript executes code line by line in sequence.

### Asynchronous Programming

Uses:

* setTimeout()
* setInterval()

to perform delayed operations without blocking program execution.

## Purpose

The purpose of this branch is to demonstrate core asynchronous programming concepts and timing events in JavaScript.
